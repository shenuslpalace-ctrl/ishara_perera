Put your photos in these folders using these exact file names.
If a file is missing, the website shows the coloured design instead.

images/
  logo.png          Header and footer logo
  teacher.png       Hero photo
  about.png         About section photo

  lessons/          Video thumbnails (16:9, 1280x720) - 6 samples included
    motion.jpg, electricity.jpg, atomic-structure.jpg,
    past-paper-2025.jpg, cell-biology.jpg, units-measurement.jpg

  books/            Book covers (3:4, 600x800) - 4 samples included
    sft-theory.jpg, mcq-1000.jpg, model-papers.jpg, short-notes.jpg

  students/         Student photos (square, e.g. 200x200)
    tharushi.jpg, kavindu.jpg, nethmi.jpg, dinuka.jpg

FREE LESSONS: in index.html, find "const LESSONS" and paste your YouTube
link into youtube:"". If you leave img:"" empty, the YouTube thumbnail
is used automatically.
